# Privacy Policy — Time Tracker — Offline

  **Effective date: 2026-04-15**

  Time Tracker — Offline is an offline time-tracking application published by nawki for the Microsoft Store.

  ## Data collection

  The app does not collect, store, transmit, or share any user data with the developer or any third party. Specifically:

  - The app has **no network activity**. It does not make any network requests.
  - The app includes **no telemetry, analytics, or crash reporting**.
  - The app includes **no auto-update logic**; updates are delivered exclusively by the Microsoft Store.
  - The app does not require **any user account or sign-in**.

  ## Data storage

  All data you create (categories, time entries, settings) is stored locally on your device in a SQLite database file at:

  %APPDATA%\time-tracker\data\timetracker.db

  This file is visible to other applications running under your Windows user account and is subject to whatever backup, sync, or access your operating system provides. It is your data. You can open, inspect, copy, or delete it at any time.

  Exports (CSV, JSON, PDF) are generated locally and saved to the location you choose. Nothing is uploaded during export.
